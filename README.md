# Игротека подкаста «Давай ходи»

Выпуски 1–10 включительно (пилотный — выпуск 1): 97 игр и 156 выбранных цитат. Нажатие на игру открывает цитаты с номером выпуска и таймкодом. Меню «Все выпуски» содержит 434 эпизода с поиском по номеру и названию. Названия выпусков взяты из файлов архива и показаны в формате «номер. название», без даты и слова «Подкаст». Выбор выпуска показывает его игры и цитаты; у выпусков без цитат есть пометка. Номер выпуска под цитатой открывает его игры. Выбор сохраняется в ссылке.

У каждой цитаты есть кнопка «Поделиться»: предпросмотр PNG с названием игры в кавычках, цитатой, логотипом «Давай ходи», номером и названием выпуска, датой и таймкодом со значком часов. Время от часа показано в формате «1:03:11». Картинку можно отправить через системное меню, если браузер поддерживает отправку файлов, или сохранить и прикрепить в мессенджере. Копирование прямой ссылки доступно отдельной кнопкой. Ссылка открывает игру и выделяет нужную цитату. На телефоне «Назад», «Все игры» и крестик возвращают в каталог с сохранением выпуска и места прокрутки. Интерфейс адаптирован для узких экранов.

Цитаты вычитаны по автоматической расшифровке; сверка с записью впереди. Счётчик показывает выбранные цитаты, а не все буквальные упоминания. Кнопка «Прослушать» запускает аудио цитаты из Cloud.ru с её таймкода и останавливает в конце отрывка. Повторное нажатие ставит на паузу; доступно продолжение и повтор. Одновременно звучит одна цитата.

Идентификаторы и ссылки игр — BoardGameGeek. Изображения коробок принадлежат соответствующим правообладателям; используются изображения из карточек BGG и иллюстрации издателей и магазинов.

Статический сайт без сборки. Для GitHub Pages: ветка `main`, корневая папка `/`. Для просмотра локально: `python3 -m http.server` в этой папке.
