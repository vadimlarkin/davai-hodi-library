# Игротека «Давай ходи»

107 игр, 286 выбранных цитат и 435 выпусков в меню.

Игры можно искать по русскому или оригинальному названию, выбирать по выпуску и сортировать по алфавиту или числу цитат. Счётчик карточки показывает выбранные цитаты, а не все буквальные упоминания.

«Золотой фонд» с кубком всегда стоит первым. Он открывает общий топ-10 цитат по сумме голосов (апвоты минус даунвоты), независимо от фильтра выпуска и поиска игр. Цитаты в карточках игр тоже расположены по убыванию суммы голосов. Голоса сохраняются на сервере; один браузер может оставить один голос на цитату, изменить его или снять повторным нажатием.

Оценки игр и подтверждение предположительной привязки к выпуску временно отложены. В каталоге отображаются игры с выбранными цитатами; в конкретном выпуске — игры с цитатами этого выпуска. Счётчиков похвалы/критики, серых кандидатов и кнопок подтверждения нет. Исходные материалы и ранее сохранённые ответы оставлены для будущего возвращения функций.

У цитат есть прослушивание отрывка, отправка PNG и прямая ссылка с выпуском и таймкодом. Идентификаторы и метаданные игр — BoardGameGeek. Изображения коробок принадлежат соответствующим правообладателям.

«Сообщить об ошибке» предлагает исправить текст или игру. Для текста можно выделить несколько слов, в том числе нажатием первого и последнего слова. Для игры есть поиск по игротеке; если карточки нет, можно ввести своё название и необязательную ссылку на BGG. Замечания сохраняются в закрытую очередь для проверки по записи; публикация и счётчики не меняются автоматически.

Кнопки прослушивания и сообщения об ошибке имеют одинаковую ширину и располагаются на одной вертикальной оси. Цитаты подготовлены по расшифровке; сверка с записью впереди.

Статический сайт без сборки. GitHub Pages: ветка `main`, корневая папка `/`.
