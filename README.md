# Игротека «Давай ходи»

107 игр, 286 выбранных цитат и 435 выпусков в меню.

Игры можно искать по русскому или оригинальному названию, выбирать по выпуску и сортировать по алфавиту или числу цитат. Счётчик карточки показывает выбранные цитаты, а не все буквальные упоминания.

«Золотой фонд» с кубком всегда стоит первым. Он открывает общий топ-10 цитат по сумме голосов (апвоты минус даунвоты), независимо от фильтра выпуска и поиска игр. Цитаты в карточках игр тоже расположены по убыванию суммы голосов. Голоса сохраняются на сервере; один браузер может оставить один голос на цитату, изменить его или снять повторным нажатием.

В выбранном выпуске игры с предположительной привязкой показываются серыми после подтверждённых. В карточке есть фрагменты с прослушиванием и отдельные ответы «Да, это про эту игру» / «Нет, это не та игра». При сумме +1 и выше карточка цветная; при нуле или ниже снова серая. Отрицательный ответ доступен и после подтверждения. Ответы сохраняются отдельно для каждой игры и выпуска, независимо от голосов за цитаты и счётчиков отзывов.

У цитат есть прослушивание отрывка, отправка PNG и прямая ссылка с выпуском и таймкодом. Идентификаторы и метаданные игр — BoardGameGeek. Изображения коробок принадлежат соответствующим правообладателям.

«Сообщить об ошибке» предлагает исправить текст, игру или отметить положительный/негативный отзыв. Для текста можно выделить несколько слов, в том числе нажатием первого и последнего слова. Для игры есть поиск по игротеке; если карточки нет, можно ввести своё название и необязательную ссылку на BGG. Замечания сохраняются в закрытую очередь для проверки по записи; публикация и счётчики не меняются автоматически.

На обложках — счётчики похвал и критических замечаний, с пометкой неподтверждённых реплик. Они считаются отдельно от голосов читателей. Цитаты подготовлены по расшифровке; сверка с записью впереди.

Статический сайт без сборки. GitHub Pages: ветка `main`, корневая папка `/`.
