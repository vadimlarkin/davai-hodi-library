# Игротека «Давай ходи»

116 игр, 340 цитат.

Цитаты подготовлены по расшифровке. Для выпусков 428 и 429 границы всех 64 цитат сверены по коротким фрагментам исходного аудио; для остальных выпусков сверка с записью впереди. Счётчик карточки показывает выбранные цитаты. Кнопка «Прослушать» воспроизводит отрывок цитаты из Cloud.ru. Идентификаторы и метаданные игр — BoardGameGeek.

Для 428 и 429 проигрыватель использует проверенные копии аудио с постоянным битрейтом для точной перемотки. Оригинальные аудиозаписи сохранены.
