# Игротека подкаста «Давай ходи»

Образец по первому выпуску: 18 игр и 25 выбранных цитат. Нажатие на игру открывает цитаты с номером выпуска и таймкодом. Меню «Все выпуски» содержит 434 эпизода с поиском по номеру и названию. Названия выпусков взяты из файлов архива и показаны в формате «номер. название», без даты и слова «Подкаст». Выбор выпуска показывает его игры и цитаты; у выпусков без цитат есть пометка. Номер выпуска под цитатой открывает его игры. Выбор сохраняется в ссылке.

Цитаты вычитаны по автоматической расшифровке; сверка с записью впереди. Счётчик показывает выбранные цитаты, а не все буквальные упоминания. Аудиопроигрывание временно отключено.

Идентификаторы и ссылки игр — BoardGameGeek. Изображения коробок принадлежат соответствующим правообладателям; образец использует иллюстрации издателей и магазинов. Одна обложка пока отсутствует.

Статический сайт без сборки. Для GitHub Pages: ветка `main`, корневая папка `/`. Для просмотра локально: `python3 -m http.server` в этой папке.
