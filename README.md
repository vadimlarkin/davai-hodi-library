# Игротека «Давай ходи»

105 игр, 276 цитат.

Цитаты подготовлены по расшифровке; сверка с записью впереди. Счётчик карточки показывает выбранные цитаты. Кнопка «Прослушать» воспроизводит отрывок цитаты из Cloud.ru. Идентификаторы и метаданные игр — BoardGameGeek.

Поиск над карточками фильтрует игры по части русского или оригинального названия. Регистр и различие е/ё не учитываются. Поиск работает вместе с выбором выпуска; запрос сохраняется в ссылке.

## Оценки на сайте — 0.6.1

В левом нижнем углу обложки в каталоге и карточке игры — компактные квадраты с белыми числами: зелёный показывает количество похвал, красный — критических замечаний. Нулевые счётчики скрыты. Лёгкий градиент и тень придают квадратам объём. Выбор выпуска фильтрует счётчики.

Блок «Как мы отзывались», раскрываемые оценочные реплики и вход в общий список оценок временно скрыты. Данные и сохранённые статусы не изменены. При наличии неподтверждённых реплик предварительный характер счётчиков отмечен в подсказке и доступном описании.

В счётчики входят собственные реплики участников с определённой игрой и направленностью. Неясные фрагменты, чужие мнения и пересечения с уже проверенной оценкой не увеличивают показатель.

`Автоматизация/pipeline_site.py` проверяет исходные подстроки и актуальность расшифровки; публичная выгрузка сохраняет только текст, таймкоды, привязки, направленность и статус. Локальные пути, хэши и служебные сведения не публикуются. Повторная сборка и `Сайт/prepare_github.py` обновляют данные оценок вместе с сайтом. Для каждого выпуска используются предварительные данные последней партии, ранее принятые записи сохраняются; отклонённые записи исключаются.
